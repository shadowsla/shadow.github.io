## 🚀 Build & Run Instructions

### Java Desktop Version
**Windows:**
```cmd
cd RPGGame
build.bat
```

**Mac/Linux:**
```bash
cd RPGGame
bash build.sh
```

**Manual Compilation:**
```bash
javac -d bin src/com/shadowrpg/**/*.java
java -cp bin com.shadowrpg.core.Game
```

### Web Version
Simply open: `RPGGame/web/index.html` in any modern web browser

### Requirements
- Java 11+ (for desktop version)
- Modern web browser (for web version)
- 2GB RAM minimum
- 100MB disk space
