Welcome to Shadow's Tower RPG

This is an epic RPG where you climb through 6 towers, each with multiple floors and challenging enemies.

Game Features:

  • 🎖️ 10 Player Ranks: F → E → D → C → B → A → S → SS → SSS → Z
  • ⚔️ 15 Different Weapon Types with unique synchronization
  • 🏰 6 Main Towers + 1 Secret 7th Tower
  • 👹 Diverse enemies with AI movement and attacks
  • 💼 Inventory system with item stacking
  • 🛠️ Crafting system with NPC support
  • 🌳 Skill trees for each weapon type
  • 🎵 Dynamic music based on location
  • 🛡️ Armor and equipment system
  • 🎁 Rare loot drops from enemies

How to Play:

  1. Press ENTER to start
  2. Select a tower with number keys (1-6)
  3. Defeat enemies on each floor
  4. Reach the boss at the top of the tower
  5. Complete all 6 towers to unlock the 7th Tower
  6. Rank up at the guild using experience
  7. Use crafting system to improve gear
  8. Master weapon skill trees to become stronger
